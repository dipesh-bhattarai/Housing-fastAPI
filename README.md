# 🏠 California House Price Predictor

A full-stack machine learning web application that predicts California housing prices using a `RandomForestRegressor` trained on the scikit-learn California Housing dataset. The project exposes a REST API for predictions and a browser-based interface for interacting with it — either one home at a time or in bulk via CSV upload.

**🔗 Live Demo:** [housing-prediction-by-dipesh.streamlit.app](https://housing-prediction-by-dipesh.streamlit.app)
**🔗 API Docs (Swagger UI):** [housing-fastapi-1.onrender.com/docs](https://housing-fastapi-1.onrender.com/docs)

> ⏳ Both services run on free-tier hosting, so the first request after a period of inactivity may take 30–60 seconds while the server wakes up. Subsequent requests are fast.

## 🧠 How It Works

1. A `RandomForestRegressor` is trained on the classic **California Housing dataset** (20,640 census block groups, 8 features each).
2. The trained model is served through a **FastAPI** backend with two prediction endpoints — one for a single record, one for bulk CSV scoring.
3. A **Streamlit** frontend provides a clean, no-code interface on top of the API, so anyone can get predictions without writing a line of code or touching the API directly.

```
User → Streamlit UI → HTTP request → FastAPI backend → RandomForest model → prediction → back to UI
```

## ✨ Features

- 🔍 **Single prediction** — interactive form with sliders and number inputs matching every model feature
- 📂 **Batch prediction** — upload a CSV, preview it, run predictions on every row, and download the results
- 📡 **Live API health check** — the UI shows whether the backend is online, along with model name and average error
- 🧾 **Input validation** — the API enforces realistic value ranges (e.g. valid California latitude/longitude bounds) via Pydantic
- 🌐 **CORS-enabled API** — safe to call from a separately hosted frontend
- 📱 **Responsive, professional UI** — clean layout with a collapsed sidebar by default so it works well on mobile too

## 🚀 Running Locally

### 1. Clone the repository

```bash
git clone https://github.com/<your-username>/<your-repo>.git
cd <your-repo>
```

### 2. Install dependencies

```bash
pip install -r requirements.txt
```

### 3. Train the model (optional — pre-trained artifacts are already included)

```bash
python train.py
```

This generates `house_model.joblib` and `house_features.joblib`.

### 4. Start the backend

```bash
uvicorn main:app --reload
```

The API will be available at `http://127.0.0.1:8000`, with interactive docs at `http://127.0.0.1:8000/docs`.

### 5. Start the frontend

In a separate terminal:

```bash
streamlit run app.py
```

The UI will open at `http://localhost:8501`.

## 📡 API Reference

### `GET /health`

Returns backend status, model type, feature list, and average error.

### `POST /predict`

Predicts the price of a single home.

**Request body:**

```json
{
  "MedInc": 5.0,
  "HouseAge": 25,
  "AveRooms": 5.5,
  "AveBedrms": 1.1,
  "Population": 1200,
  "AveOccup": 3.0,
  "Latitude": 36.5,
  "Longitude": -119.5
}
```

**Response:**

```json
{
  "predicted_price": "$243,000",
  "predicted_price_short": "2 hundred thousands dollars",
  "fidence_range": "$204,000 to $282,000"
}
```

### `POST /predict-file`

Accepts a CSV file (`multipart/form-data`) containing the columns below and returns a CSV with an added `predicted_columns_usd` column.

**Required columns:** `MedInc`, `HouseAge`, `AveRooms`, `AveBedrms`, `Population`, `AveOccup`, `Latitude`, `Longitude`

## 📊 Model Details

| Feature | Description |
|---|---|
| `MedInc` | Median income in the block group (tens of thousands of $) |
| `HouseAge` | Median house age in the block group (years) |
| `AveRooms` | Average number of rooms per household |
| `AveBedrms` | Average number of bedrooms per household |
| `Population` | Total population in the block group |
| `AveOccup` | Average number of household members |
| `Latitude` | Block group latitude |
| `Longitude` | Block group longitude |

The model is a `RandomForestRegressor` (100 estimators) trained with an 80/20 train-test split (`random_state=42`), achieving a mean absolute error of roughly **$39,000** on the held-out test set.

## ☁️ Deployment

- **Backend** is deployed on [Render](https://render.com) as a web service, using the `Procfile` to run `uvicorn main:app --host 0.0.0.0 --port $PORT`.
- **Frontend** is deployed on [Streamlit Community Cloud](https://streamlit.io/cloud), pointed at the Render API URL.
- CORS is enabled on the backend so the two independently hosted services can communicate.
